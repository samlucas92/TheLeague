# The League

React/Vite frontend for a flexible league-management app.

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` if your API is not running at the default:

```bash
VITE_API_BASE_URL=http://localhost:5000/api
```

## Current slice

The app includes account registration/login, my leagues, create league, join by code, league workspace navigation, challenges, point submission, admin approval, leaderboard, members, and Points Feed.
